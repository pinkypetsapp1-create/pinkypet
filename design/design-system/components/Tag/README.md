# Tag
Etiqueta no interactiva para atributos y estados.

## Variantes
- **Atributo** (`pp-tag`): 24 px, `corner-small`, borde `outline`, texto `on-surface-variant`, `label-small-emphasized`. Es la etiqueta «Necesidades especiales» de la tarjeta y la ficha. Dentro de `AnimalCard` no pasa del ancho de la tarjeta: si no cabe, parte el texto en dos líneas (24 px es un alto mínimo).
- **Estado** (`pp-status`): 28 px, `corner-full`, `label-medium-emphasized`. «En proceso», «Cancelada» y «No disponible» con borde `outline`; «Adopción finalizada» con `pp-status--done` (`inverse-surface`).

## Tokens
`outline`, `on-surface`, `on-surface-variant`, `inverse-surface`, `inverse-on-surface`, `corner-small`, `corner-full`.

## Fuente
Wireframe de fidelidad media: Mascotas, Ficha, Estado de la solicitud.
