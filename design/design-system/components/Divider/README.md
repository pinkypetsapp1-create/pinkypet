# Divider
Línea de 1 px en `outline-variant`.

## Variantes
- `pp-divider` (`<hr>`): pie de la tarjeta de mascota, separación de bloques.
- `pp-divider-label`: «o» entre la acción principal y «Continuar con Google».

## Tokens
`outline-variant`, `on-surface-variant`, `body-small`.

## Fuente
Wireframe de fidelidad media: Login, Registro, tarjeta de mascota.
