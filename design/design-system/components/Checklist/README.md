# Checklist
Lista contenida con un `check` por elemento, para leer los requisitos como «lo que necesitas tener listo».

## Anatomía
Tarjeta outlined (`surface-container-lowest` + `outline-variant`, `corner-medium`) con filas de 56 px como mínimo, separadas por divisores. Cada fila lleva el icono `check` de 24 px en `primary` y el texto en `body-large`. Encima van el título de sección («Requisitos para adoptar») y la frase «Tenlos listos antes de enviar tu solicitud.» en `body-medium` con `on-surface-variant`.

## Accesibilidad
`<ul>` real; el icono es decorativo.

## Tokens
`surface-container-lowest`, `outline-variant`, `primary`, `on-surface`, `corner-medium`.

## Fuente
Wireframe de fidelidad media: Cómo adoptar.
