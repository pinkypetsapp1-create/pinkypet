# AccountPrompt
Fila centrada de 48 px con una pregunta en `body-medium` (`on-surface-variant`) y un botón de texto con icono.

## Variantes del wireframe
- «¿Aún no tienes cuenta?» + `person_add` «Regístrate».
- «¿No tienes cuenta?» + `person_add` «Regístrate» (Login).
- «¿Ya tienes cuenta?» + `login` «Inicia sesión».

En Inicio y Mi perfil sin cuenta aparecen las dos filas apiladas.

## Tokens
`on-surface-variant`, `primary`.

## Fuente
Wireframe de fidelidad media: Inicio, Mi perfil, Login, Registro.
